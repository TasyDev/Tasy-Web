# Typography
Font family, sizes, and line-heights used in the Figma landing page.

## Font families

- <code>--font-sans</code>: <code>var(--font-sans)</code>
- <code>--font-mono</code>: <code>var(--font-mono)</code>

## Tailwind usage

```html
<h2 class="font-sans text-[48px] leading-[48px]">Heading</h2>
<p class="font-sans text-[18px] leading-[29.25px] text-text-muted">Body</p>
```
