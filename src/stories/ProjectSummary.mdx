# Tasy-Web: Resumen del Proyecto

Bienvenido a la documentación oficial del sistema de diseño y componentes de **Tasy-Web**.

## 🛠 Tecnologías Principales
- **Core:** Astro (`^6.3.3`)
- **Librería UI:** React (`^19.2.6`)
- **Estilos:** Tailwind CSS v4 (`^4.3.0`)
- **Documentación de UI:** Storybook (`^10.4.0`)
- **Testing:** Vitest y Playwright
- **Mocking:** MSW (Mock Service Worker)

## 📁 Estructura del Proyecto
El código fuente está organizado en la carpeta `src/` de la siguiente manera:
- `assets/`: Recursos estáticos (imágenes, SVGs).
- `components/`: Componentes UI reutilizables (React / Astro).
- `layouts/`: Plantillas base para las diferentes páginas.
- `pages/`: Vistas y rutas de la aplicación.
- `styles/`: Hojas de estilo y configuraciones base.
- `stories/`: Documentación centralizada y pruebas visuales (donde te encuentras ahora).

> **Nota:** La carpeta de `stories` ha sido limpiada de componentes de ejemplo.
